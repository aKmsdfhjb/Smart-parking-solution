# Smart Parking Nepal — Video Production Brief

**Target:** 45 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

Use real screens from the current React PWA. Show map search and booking flows only if they work in the configured environment. Do not simulate successful payments, QR validation, live availability or push notifications without verified test evidence. Avoid exposing API keys or user records.

## Shot list

0–5s: title. 5–15s: real map/search screen. 15–25s: parking listing and booking UI. 25–34s: owner dashboard or QR flow only if tested. 34–40s: architecture overview (React, Firebase, Maps, payment integrations). 40–45s: repo and integration-verification note.

## Voiceover draft

A parking discovery and booking PWA concept for Nepal, combining location-aware search, booking workflows and owner tools. Show only verified working flows.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response, payment, authentication or integration shown.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

## Generation prompt

Create a 45 seconds 16:9 1080p editorial software-project showcase for “Smart Parking Nepal”. Follow a warm ivory, black serif and vermilion monospaced Swiss portfolio aesthetic with precise grid alignment, thin rules, subtle transitions and clean screen-recording inserts. Use authentic project screenshots and the shot list above. Keep typography crisp and restrained. Do not fabricate UI, model outputs, payment success, performance metrics, users, testimonials or product capabilities. Avoid generic AI robots and neon sci-fi visuals. Finish on a quiet title card with the project name and GitHub repository.
