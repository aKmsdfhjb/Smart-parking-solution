# Smart Parking Nepal — Project Wiki

React and TypeScript PWA for parking discovery, booking, owner workflows and related services. The frontend integrates Firebase, Google Maps and payment providers; each production integration must be configured and tested in its own environment.

## Quick start

```bash
npm install
npm run dev
```
Configure Firebase, Google Maps and payment-provider settings using the project setup guide. Never place private server credentials in browser code.

Check the repository README and Actions history before treating a feature as production-ready.
